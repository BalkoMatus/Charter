How Charter works

Charter reads a sheet by its row labels rather than its cell addresses, and holds every figure it draws to one standard. Each figure shows the cells it came from.

The standard

There is no industry standard for figures in a financial document, so Charter defines one and writes it down. The table below is generated from the same values the renderer uses, so it cannot drift from what is drawn. Every figure on screen, every PNG and SVG, and every chart written into Excel is built from it.

Switching between Word and slides does not re-lay anything out. It stretches the millimetre, so type, rules, markers and padding grow together and a figure keeps its proportions at either size. Set the width by hand if the target width is not the default.

Getting started

  1. Load a workbook.

    Use the demo, or open your own .xlsx from the panel on the left. Starting from nothing, Download Excel template gives you a workbook with the blocks, formulas and labels already in place. Replace the blue cells and load it back in. Nothing is uploaded, the file is read in this browser.

  2. Check what bound.

    The Bindings list shows which slots matched and what they matched. An unlit slot means that block is not on this sheet, and Charter omits the figure rather than guessing.

  3. Set the standard once.

    Width, typeface, colour or greyscale and the source note apply to every figure at once. One standard for the whole document.

  4. Export into Word or a deck.

    Pick the target at the top of the panel. Each figure exports as a PNG (300 dpi, fixed physical size) or an SVG. Insert at 100% and every figure lands at the same scale.

  5. Or write charts back into Excel.

    Write charts into the workbook returns a copy of your file with live chart objects in it. More on this below.

How the binding works

Charter looks for a section headed “Revenue” wherever it sits on the sheet, so pasting your data a row lower does not break it. A chart tied to a fixed range would carry on drawing and plot the wrong cells.

Sheets without labels. The Data: marker is a shortcut, not a requirement. Without it Charter takes the first row holding an unbroken run of numbers, then the column to its left that labels the most rows below. A row equal to the sum of the others in every period is treated as the total whatever it is called, so “Consolidated” and “Group” are never stacked on top of the parts they contain.

The source panel

Every figure carries its audit trail. It shows the block and group it matched, the range behind each row drawn, any row read but not drawn and why, and where the unit came from. Turn it off under Bindings for a clean view.

Writing native charts back into Excel

You get a copy of your file with real Excel charts in it, not pictures. Every series is a formula pointing at the cells the figure was read from (Sheet!$W$32:$AE$32), so editing the sheet redraws the chart in Excel. The chart parts hold formulas only, with no cached values.

The charts are written to the same standard as the figures on screen, with the typeface, text sizes, palette and figure width you set here.

Eight types are covered. Column, stacked column with the total above each bar, multi series line, a date axis line for price series, a combo chart on a secondary axis, a football field range built from the sheet’s own Delta column, and a waterfall with the total marked as a subtotal. Where a sheet lacks what a figure needs, that figure is skipped.

Chart XML, drawing anchors, relationship parts and the ZIP writer are all written here. Everything already in your workbook is copied through unchanged.

Known limits

  • Only the first worksheet in a workbook is read.
  • The bindings panel is read only. To point a slot at a differently named group you still rename the row on the sheet.
  • Native waterfall charts need Excel 2016 or later. Older versions show a fallback message instead of failing.
